# Calculadora en Python

##  Descripción del proyecto

Este proyecto consiste en el desarrollo de una calculadora básica utilizando el lenguaje de programación **Python**.

Su objetivo es poner en práctica los fundamentos de programación, especialmente la creación de funciones, el uso de operadores aritméticos y la organización del código.

##  Objetivos

- Comprender el funcionamiento de las operaciones matemáticas en Python.
- Implementar funciones para realizar cálculos.
- Practicar el uso de Git y GitHub para el control de versiones.
- Fomentar el trabajo colaborativo y la documentación del código.

## Funcionalidades

El proyecto contempla las siguientes operaciones:

| Operación | Descripción | Estado |
|---|---|---|
|  Suma | Sumar dos números | Implementada |
|  Resta | Restar dos números | Implementada |
|  Multiplicación | Multiplicar dos números | Implementada |
|  División | Dividir dos números | Pendiente |
|  Potencia | Calcular potencias | En desarrollo |

##  Tecnologías utilizadas

- **Python:** lenguaje principal de programación.
- **Visual Studio Code:** editor de código.
- **Git:** sistema de control de versiones.
- **GitHub:** plataforma para almacenar y colaborar en el proyecto.
- **Markdown:** lenguaje utilizado para documentar el repositorio.

## Estructura del proyecto

```text
Calculadora/
├── ejercicio.py
├── hola.py
└── README.md
```

**Descripción de los archivos:**

- `ejercicio.py`: contiene las funciones de las operaciones matemáticas.
- `hola.py`: archivo reservado para el desarrollo.
- `README.md`: documentación del proyecto.

## Instalación

### 1. Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/FernandoMF17/Calculadora.git
```

### 2. Ingresar a la carpeta

```bash
cd Calculadora
```

### 3. Abrir el proyecto en Visual Studio Code

```bash
code .
```
